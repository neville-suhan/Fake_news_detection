# Fake News Detection System

## 📌 Project Overview
A Machine Learning-based Fake News Detection System that classifies news articles as **Real News** or **Fake News** using Natural Language Processing (NLP).

## 🚀 Features
- Enter news headlines and article content.
- Predict Real or Fake News.
- Display prediction confidence and probability scores.
- User-friendly web interface.
- FastAPI backend for model deployment.

## 🛠️ Technologies Used
- Python
- Machine Learning
- NLP
- TF-IDF
- Linear SVM
- LSTM
- FastAPI
- HTML, CSS and JavaScript
- Scikit-learn, TensorFlow

## 📂 Dataset
Kaggle Fake News Dataset containing news articles labelled as Real or Fake.

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:
   ```bash
   cd Fake_news_Project_NLP
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   python -m uvicorn app:app --reload
   ```

5. Open in your browser:
   ```text
   http://127.0.0.1:8000
   ```

## 📊 Models
- LSTM
- TF-IDF + Linear SVM

## 🎯 Objective
To help users identify potentially misleading news articles through automated text classification using Machine Learning and NLP.
